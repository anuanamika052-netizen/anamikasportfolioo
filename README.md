# Anamika M — Personal Portfolio

A responsive, vibrant-gradient portfolio made with HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — colors, layout and responsive styling
- `script.js` — mobile navigation and profile image fallback
- `images/profile.jpg` — add your own profile photo here

## Add your profile photo
1. Choose a clear photo of yourself.
2. Rename the image exactly `profile.jpg`.
3. Put it inside the `images` folder.
4. Upload/commit the updated file to GitHub.
The page uses an initials placeholder until the photo is added.

## Publish with GitHub Pages
1. Sign in at https://github.com.
2. Create a new repository named `anuanamika052-netizen.github.io` (or use another repository name).
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder. Keep the folder structure unchanged.
4. Open the repository's **Settings** tab.
5. Select **Pages** from the left sidebar.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. Your site will be available at:
   `https://anuanamika052-netizen.github.io/`

If you use a repository with a different name, the URL will usually be:
`https://anuanamika052-netizen.github.io/REPOSITORY-NAME/`

## Update the website later
Edit the relevant file in GitHub or upload the changed file and commit it. GitHub Pages will publish the changes automatically.
